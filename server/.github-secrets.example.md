# Required GitHub Secrets for Deployment

This document lists all the environment variables that need to be configured as GitHub Secrets for deploying the Flowbites Marketplace application.

## 📋 Overview

The application uses GitHub Secrets to store sensitive configuration values. These secrets are injected at runtime, ensuring no credentials are hardcoded in the Docker images.

## 🔐 Required GitHub Secrets

### Database & Authentication
| Secret Name | Description | Required |
|-------------|-------------|----------|
| `MONGODB_URI` | MongoDB connection string with credentials | ✅ Yes |
| `JWT_ACCESS_SECRET` | Secret key for signing JWT access tokens | ✅ Yes |
| `JWT_REFRESH_SECRET` | Secret key for signing JWT refresh tokens | ✅ Yes |

### Payment Processing (Stripe)
| Secret Name | Description | Required |
|-------------|-------------|----------|
| `STRIPE_SECRET_KEY` | Stripe API secret key (starts with `sk_test_` or `sk_live_`) | Optional* |
| `STRIPE_WEBHOOK_SECRET` | Stripe webhook signing secret (starts with `whsec_`) | Optional* |
| `STRIPE_CONNECT_CLIENT_ID` | Stripe Connect OAuth client ID (starts with `ca_`) | Optional* |

*Optional - payments run in demo mode if not configured.

### Email Service (Resend)
| Secret Name | Description | Required |
|-------------|-------------|----------|
| `RESEND_API_KEY` | Resend API key for sending transactional emails | Optional† |

†Optional - emails are logged to console if not configured.

### Media Storage (Cloudinary)
| Secret Name | Description | Required |
|-------------|-------------|----------|
| `CLOUDINARY_API_KEY` | Cloudinary API key | Optional‡ |
| `CLOUDINARY_API_SECRET` | Cloudinary API secret | Optional‡ |

‡Optional - falls back to local storage if not configured.

## 🌍 Environment-Specific Secrets

You should configure separate secrets for each environment:

### Production Environment (`main` branch)
```bash
# Set these secrets in GitHub: Settings → Secrets and variables → Actions
MONGODB_URI=mongodb+srv://user:password@prod-cluster.mongodb.net/flowbites-prod
JWT_ACCESS_SECRET=<generate-secure-random-string>
JWT_REFRESH_SECRET=<generate-secure-random-string>
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_CONNECT_CLIENT_ID=ca_...
RESEND_API_KEY=re_...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...
```

### Development Environment (`develop` branch)
```bash
# Set these secrets with different values for development
MONGODB_URI=mongodb+srv://user:password@dev-cluster.mongodb.net/flowbites-dev
JWT_ACCESS_SECRET=<different-secure-random-string>
JWT_REFRESH_SECRET=<different-secure-random-string>
STRIPE_SECRET_KEY=sk_test_...
# ... (use test/staging values for development)
```

## 🔧 Non-Sensitive Configuration

These variables are **NOT secrets** and can be set in the workflow directly or in a committed `.env` file:

```bash
# Server Configuration
NODE_ENV=production
PORT=5001

# CORS Configuration
CLIENT_URL=https://flowbites.com
SITE_URL=https://flowbites.com

# JWT Expiration
JWT_ACCESS_EXPIRES_IN=15m
JWT_REFRESH_EXPIRES_IN=7d

# Stripe Configuration
STRIPE_PLATFORM_FEE_PERCENT=20

# File Upload
UPLOAD_DIR=./uploads
MAX_FILE_SIZE=104857600
ALLOWED_FILE_TYPES=.zip,.jpg,.jpeg,.png,.gif,.webp,.svg

# Download Security
DOWNLOAD_TOKEN_EXPIRES_MINUTES=60

# Rate Limiting
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX_REQUESTS=100

# Email Configuration
FROM_EMAIL=noreply@flowbites.com
FROM_NAME=Flowbites Marketplace

# Cloudinary (non-sensitive)
CLOUDINARY_CLOUD_NAME=your_cloud_name
```

## 📝 How to Add Secrets to GitHub

1. Go to your repository on GitHub
2. Click **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Add each secret with its name and value
5. Click **Add secret**

## 🔐 Generating Secure Secrets

For JWT secrets, use a cryptographically secure random string generator:

```bash
# Generate JWT secrets (256-bit hex)
openssl rand -hex 64
```

**⚠️ Important Security Notes:**

1. **Never commit real secrets to the repository**
2. **Use different secrets for production and development**
3. **Rotate secrets regularly** (especially JWT secrets)
4. **Use strong, randomly generated values** for all secrets
5. **Never share secrets via email, chat, or other insecure channels**

## 🐳 Using Secrets in Docker

When running the Docker images locally, use an `.env` file (don't commit it):

```bash
# .env (local development)
MONGODB_URI=mongodb://localhost:27017/flowbites-marketplace
JWT_ACCESS_SECRET=your-local-dev-secret
JWT_REFRESH_SECRET=your-local-dev-secret
# ... other secrets

# Run with environment file
docker run --env-file .env ghcr.io/your-username/flowbites-api:develop
```

## 🚀 Deployment Platforms

Different platforms handle secrets differently:

- **Docker Compose:** Use a `.env` file (not committed to git)
- **Kubernetes:** Use ConfigMaps (non-sensitive) + Secrets (sensitive)
- **Railway/Vercel:** Use their environment variable dashboard
- **AWS ECS:** Use ECS task definitions + Secrets Manager
- **Google Cloud Run:** Use Secret Manager
